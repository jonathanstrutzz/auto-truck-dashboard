# Auto Truck Estética — Dashboard de Contas a Receber

Painel executivo (HTML/JS single-page) para acompanhamento de faturamento, recebimentos e metas.

## Como usar
Abra o arquivo `index.html` diretamente no navegador, ou publique via GitHub Pages.

## Login padrão
Usuário e senha são gerenciados dentro do próprio sistema (tela de login). O primeiro acesso cria automaticamente um usuário administrador — troque a senha assim que possível pela seção "Usuários".
